# AAI and DSAI 4323/5323 Final
## University of Oklahoma

This repository contains the files for the instruction and assignment for _Final Project: Fairness Analysis and Mitigation_.
To complete the assignment you will run each notebook and answer the questions in the assignment. You will
upload your answers to the questions in a PDF onto the Canvas assignment submission page. You will also save your code notebooks
to PDF and upload those as well. Follow the instructions to the assignment carefully. The total assignment is worth 1000 points.
